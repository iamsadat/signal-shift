Privacy policy

Last updated: November 2, 2026

This policy covers Signal Shift Autopilot, a private tool used only by the owner of the Signal Shift YouTube channel. It is not offered to the public, and nobody else signs in to it.

YouTube API Services

The tool uses YouTube API Services to upload the channel's own videos, set their titles, descriptions, thumbnails, captions and playlists, schedule when they go public, and read the channel's own analytics. It also reads public video information (titles, view counts, publish dates) from YouTube search to research topics. By using it, the channel owner agrees to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What is stored, and where

The sign-in token and the channel's video and analytics data are stored only on the channel owner's own computer. They are used to publish videos and to learn which videos perform well. Nothing is sold, shared with third parties, or used for advertising. No personal data about viewers is collected.

Data retention and deletion

Public YouTube data used for topic research (video titles, view counts) is refreshed or deleted within 30 days; the tool deletes it automatically. The channel's own video and analytics data is kept only while access is authorized.

Revoking access

Access can be revoked at any time from the Google security settings page. If access is revoked, all stored YouTube data is deleted within 7 days. Deleting the tool's local data folder removes everything it stored immediately.

Contact

Questions about this policy can be sent through the Signal Shift YouTube channel.
